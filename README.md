# Sensor de Aparcamiento

Proyecto Arduino que utiliza un sensor ultrasónico HC-SR04, una pantalla LCD y tres LEDs para indicar distancia de aparcamiento.

## Archivos

- `Sensor de aparcamiento.ino`: código principal del proyecto.

## Componentes

- Arduino UNO
- Sensor ultrasónico HC-SR04
- Pantalla LCD 16x2
- LED rojo, amarillo y verde
- Buzzer

## Uso

1. Conecta el sensor y los LEDs según el código.
2. Carga `Sensor de aparcamiento.ino` en tu placa Arduino.
3. Observa la distancia en la pantalla y el comportamiento de los LEDs/buzzer.
